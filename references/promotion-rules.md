# Promotion Rules

Use these rules to decide what stays raw and what becomes durable wiki knowledge.

## Promote To Source Note

Register a source when at least one is true:

- it supports a likely reusable claim
- it is a primary or high-authority source
- it anchors chronology, terminology, or comparison
- later agents will likely need to revisit it

Do not register everything. Low-signal duplicates should stay out.

## Promote To Claim

Promote a point into a claim when it is:

- specific enough to be tested or cited
- useful for downstream writing or content
- supported by at least one durable source note

Good claim:

- "Steamships improved route reliability for long-distance shipping in the 19th century."

Weak claim:

- "Steamships were important."

## Confidence Labels

- `high`: directly supported by strong evidence or repeated strong sources
- `medium`: supported but still somewhat interpretive
- `working`: plausible but should be treated as provisional
- `low`: keep only if useful as a tracked hypothesis

## Promote To Image Note

Register an image only when it helps prove or clarify something:

- map
- diagram
- archival photo
- timeline figure
- before/after comparison

Each image should link to at least one page or claim when possible.

## Promote To Open Question

Create an open question when:

- a contradiction remains unresolved
- a likely important gap still exists
- a downstream agent could overstate certainty without the warning

Do not hide uncertainty in prose. Track it explicitly.

## Conflict Handling

When two strong sources disagree:

- store both relevant source notes
- avoid forcing a premature canonical claim
- record the disagreement as an open question or lower-confidence claim

## Snapshot Rule

Only after promotion should the topic snapshot be refreshed. The snapshot is a compiled read model, not the place where first-pass reasoning happens.
